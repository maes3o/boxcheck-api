Статус: **research-only**. Жодного production-коду, формул, API чи UI. Закомічено 03.10.2026 (див. `PROGRESS.md`); каталог `reference/` (нормалізовані дані з вхідних PDF) **свідомо не в репозиторії** — його зберігання й походження ще не вирішені, тому відтворення скриптів потребує вхідних PDF і локально згенерованого `reference/`.

Позначки: **OBSERVED** — прочитано прямо з PDF · **DERIVED** — пораховано з OBSERVED ·

## 0. Межі й IP

- Використано **лише PDF**. ARD-файли в цьому кроці не читались, їхні формули/параметри не використовувались.
- Вхідні PDF і ARD у репозиторій не копіювались; в JSON лише sha256 і ім'я файлу.
- L/W/D беруться з імен файлів — це **UNVERIFIED** мітки (у PDF немає тексту з розмірами).

## 1. Метод

PDF → власний parser content-stream (суворий: невідомий оператор = помилка) → примітиви line/cubic →
крос-перевірка з PyMuPDF (збіг по недегенерованих сегментах) → mm → `reference/normalized/<L>x<W>x<D>.json`
(кожен примітив: `raw_pt`, `page_mm`, `norm_mm` (початок у bbox), `cal_mm` (калібровано, HYPOTHESIS)) →
`_comparison.json` (попарні дельти, індекс-в-індекс).

## 3. Що виводиться з 4 PDF, а що ні

| Питання | З 4 PDF | Примітка |
|---|---|---|
| Топологія родини, ролі Cut/Crease | **Так** (OBSERVED) | Роль із імені каналу |
| Які координати залежать від L / W / D і з яким k | **Так** (DERIVED) | `structural-spec.md` A–E; при прийнятому калібруванні |
| Абсолютні мм | **Умовно** | Незалежна оцінка одиниці `0.7938 ± 0.0005 мм` спирається на різниці міток з імен файлів; зразка з відомою ззовні міркою немає |
| Незалежність осей (x від L, y від W) | **Так** | Для цього одного стилю |
| Закон ширини слота від L | **Ні** | 2 значення L; потрібні ≥4 |
| Закон радіусів заокруглень від D/W | **Ні** | 2 значення D, 1 значення W з нелінійністю; потрібні ≥4 |
| Вплив caliper (товщини) | **Ні** | Одна дошка в усіх зразках; константи й caliper не розділяються |
| Інші слоти/flap-стилі | **Ні** | Один стиль, один slot |
| Точність L/W/D як заявлено | **Частково** | Відносні Δ сходяться з мітками; абсолютні значення з іменами не звірені |
| Відповідність FEFCO/ECMA | **Не оцінювалось** | Спершу геометрія, потім зіставлення топологій |

## 4. Наступні експерименти (в ArtiosCAD, без зміни коду)

1. Перезапис **усіх** зразків з однаковими параметрами експорту (масштаб 1:1, без «вписати в сторінку») — прибирає гіпотезу F5.
2. Той самий L/W/D, **інший board/caliper** — відокремлює caliper від констант (F9).
3. Серія D (20, 25, 30, 35, 40, 50) — закон заокруглень (F8); серія L — ширина слота (F7); серія W.
4. Окремо з'ясувати, чи Crease-кінці лежать на Cut-контурі (топологічний граф) — тут не перевірялось.
